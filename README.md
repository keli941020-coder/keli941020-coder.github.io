# 李珂 · 作品集占位页

单文件 HTML（`index.html`），本地双击即可打开。

## 部署到 GitHub Pages（可选，推荐）
1. 在 GitHub 新建仓库，推荐命名为 `你的用户名.github.io`（或个人主页仓库）；
2. 把本文件夹内容推上去；
3. 在仓库 Settings → Pages → Source 选择 main 分支 / root；
4. 访问 `https://你的用户名.github.io`。
